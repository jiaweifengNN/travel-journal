## 目录结构

```
travel-journal/
├── README.md                  # 本文件：总索引 + 记录规则
├── _template/                 # 模板：每次新旅行复制一份改名
│   └── 旅行模板.md
└── 2026-十一平潭自驾/          # 每次旅行一个文件夹，命名：YYYY-名称
    ├── 行程规划.md             # 行前：路线、逐日安排（会持续迭代版本）
    ├── 行前清单.md             # 预约 / 物品 / 车辆，出发前逐项勾掉
    ├── 花销记录.md             # 账本：当天花销当天记，回来算总账
    ├── 旅行日记.md             # 旅途中：所见所闻、吃了什么、住哪里、感想
    ├── 行程.html               # 动态行程页（可交互版）
    └── photos/                 # 照片按天放（建议压缩后再传，单张 < 2MB）
```

## 记录规则（跟自己约法三章）

1. **新旅行 = 新文件夹**：复制 `_template/旅行模板.md`，按 `YYYY-名称` 建目录，登记到上面的索引表。
2. **当天的事当天记**：日记和花销不过夜，过夜就忘。
3. **行程规划会变**：计划迭代就在 `行程规划.md` 里改并更新版本号（V1 → V2 → …），旧的划掉不删，能看到计划是怎么演化的。
4. **照片进 `photos/`**：按 `MMDD-说明.jpg` 命名；大视频不上传，放网盘后在日记里贴链接。
5. **提交信息用一句话讲清楚**：`行程: 平潭V2 去掉武夷山改霞浦` 比 `update` 强一百倍。

## 花销口径

- 分类只有六种：`交通` `住宿` `餐饮` `门票` `购物` `其他`，方便回来汇总。
- 记账记到手金额，多人拼的注明人均。
