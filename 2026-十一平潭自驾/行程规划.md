## 基本信息

- **时间**：2026.09.30 晚 – 10.08
- **出发地 / 结束地**：武汉
- **路线**：武汉 → 景德镇 → 篁岭 → 武夷山 → 平潭岛 → 抚州（夜宿）→ 南昌 → 武汉
- **硬约束**：10.5 上午必须到南昌；10.7 参加朋友婚礼
- **总里程**：去程约 1100 km（边走边玩），返程约 750 km（一夜 + 一晨）

## 逐日安排

### 9.30（周三）出发夜
- 19:00 武汉出发，G70 福银高速 → 景德镇（330km / 约4h）
- 23:00 到，宿陶溪川周边
- 省钱点：高速免费以**驶离出口时间**为准（10.1 0:00 起），服务区磨到 0 点后下高速

### 10.1（周四）景德镇
- 上午：御窑厂国家考古遗址公园 + 陶阳里历史街区
- 午餐：冷粉、饺子粑、瓷泥煨鸡
- 下午：中国陶瓷博物馆（免费，**须预约**）
- 晚上：陶溪川文创夜市

### 10.2（周五）篁岭 → 武夷山
- 08:00 出发 → 篁岭（85km / 1.5h），**门票+索道提前买**
- 09:30 索道上山：晒秋人家、五桂堂晒台（十月晒秋正季）
- 14:00 下山 → 武夷山（250km / 3h），宿三姑度假区

### 10.3（周六）武夷山 → 平潭
- 07:30 九曲溪竹筏漂流（最早班，**预约秒光盯紧**）
- 09:30 天游峰
- 15:00 出发 → 平潭（430km / 5h，跨平潭海峡公铁大桥）
- 20:00 上岛，海鲜大排档，宿县城/坛南湾

### 10.4（周日）平潭环岛日（全程高光）
- 08:30 猴研岛 · 68海里景区（约66元）
- 11:30 北港村石头厝 + 午餐
- 14:00 北部生态廊道（10km 景观带）
- 16:00 猫头墘 / 国彩村
- 17:00 长江澳风车田等日落（约18:00，**提前1小时占位**）
- 18:30 连夜返程 → 宿抚州/南城（620km / 约6.5h，建议双驾）
- 备选：16:00 提前离岛（22:30 到抚州），代价是错过日落

### 10.5（周一）晨抵南昌
- 07:30 出发 → 09:00 到南昌（100km / 1.5h）✔ 硬约束达成
- 中午：拌粉 + 瓦罐汤
- 晚上：水煮第一顿（谭记东湖总店 或 小欧）

### 10.6（周二）南昌
- 上午：滕王阁（**预约**）
- 12:00 万寿宫历史文化街区扫街
- 19:30 秋水广场音乐喷泉
- 21:00 水煮第二轮（胖子 或 英嫂深夜档）

### 10.7（周三）朋友婚礼
- 全天：婚礼，见老朋友

### 10.8（周四）返武汉
- 08:00 最后一碗拌粉，G70 返汉（340km / 4h），中午到家
- 注意：8 号 24:00 后高速开始收费，中午前到家无压力

## 关键提醒

1. 高速免费：10.1 0:00 – 10.8 24:00，7座以下免费
2. 必须预约：中国陶瓷博物馆、篁岭索道、九曲溪竹筏、滕王阁（出发前 3–7 天最后窗口）
3. 10月平潭已过蓝眼泪高发期（4–6月为主），看到是彩蛋
4. 岛上风大：帽子墨镜；车别开上沙滩；环岛路限速60
