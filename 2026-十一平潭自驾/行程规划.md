## 基本信息

- **时间**：2026.09.30 晚 – 10.08
- **出发地 / 结束地**：武汉
- **路线**：武汉 → 婺源（篁岭）→ 武夷山 → 平潭岛 → 抚州（夜宿）→ 南昌 → 武汉

## 逐日安排

### 9.30（周三）出发夜
- 19:00 武汉出发 → 婺源县城（450km / 约5h）
- 00:30 到，宿县城文博路/蚺城路一带（凌晨到店提前跟老板打招呼）
- 省钱点：高速免费以**驶离出口时间**为准（10.1 0:00 起），服务区磨到 0 点后下高速

### 10.1（周四）篁岭晒秋一整天
- 07:30 出发 → 篁岭（20km / 40min），**门票+索道提前买**
- 08:30 索道上山：晒秋人家、五桂堂晒台（十月晒秋正季，赶早班避开大部队）
- 12:00 山上午餐：蒸汽糕、清明粿、婺源糊豆腐
- 14:00 垒心桥 · 梯田观景 · 怪屋
- 16:00 下山，体力好加月亮湾拍夕阳（免费）
- 宿婺源县城（连住第二晚）

### 10.2（周五）婺源晨景 → 武夷山
- 07:30 晨雾婺源（月亮湾/李坑外围自选）
- 09:30 出发 → 武夷山（250km / 3h）
- 14:30 天游峰（俯瞰九曲溪）
- 宿三姑度假区（**预约明早九曲溪竹筏，秒光盯紧**）

### 10.3（周六）武夷山 → 平潭
- 07:30 九曲溪竹筏漂流（最早班）
- 12:00 出发 → 平潭（430km / 5h，跨平潭海峡公铁大桥）
- 19:00 上岛，海鲜大排档，宿县城/坛南湾

### 10.4（周日）平潭环岛日（全程高光）
- 08:30 猴研岛 · 68海里景区（约66元）
- 11:30 北港村石头厝 + 午餐
- 14:00 北部生态廊道（10km 景观带）
- 16:00 猫头墘 / 国彩村
- 17:00 长江澳风车田等日落（约18:00，**提前1小时占位**）
- 18:30 连夜返程 → 宿抚州/南城（620km / 约6.5h，建议双驾）
- 备选：16:00 提前离岛（22:30 到抚州），代价是错过日落

### 10.5（周一）晨抵南昌
- 07:30 出发 → 09:00 到南昌（100km / 1.5h）✔ 硬约束达成
- 中午：拌粉 + 瓦罐汤
- 晚上：水煮第一顿（谭记东湖总店 或 小欧）

### 10.6（周二）南昌
- 上午：滕王阁（**预约**）
- 12:00 万寿宫历史文化街区扫街
- 19:30 秋水广场音乐喷泉
- 21:00 水煮第二轮（胖子 或 英嫂深夜档）

### 10.7（周三）朋友婚礼
- 全天：婚礼，见老朋友

### 10.8（周四）返武汉
- 08:00 最后一碗拌粉，G70 返汉（340km / 4h），中午到家
- 注意：8 号 24:00 后高速开始收费，中午前到家无压力

## 关键提醒

1. 高速免费：10.1 0:00 – 10.8 24:00，7座以下免费
2. 必须预约：篁岭索道、九曲溪竹筏、滕王阁（出发前 3–7 天最后窗口）
3. 10月平潭已过蓝眼泪高发期（4–6月为主），看到是彩蛋
4. 岛上风大：帽子墨镜；车别开上沙滩；环岛路限速60
