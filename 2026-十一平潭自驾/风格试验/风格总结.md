## 二、每个仓库教了我什么

### 1. guizang-ppt-skill-mod —— 「锁死 token，单一锚点色」
- **双风格**：默认「电子杂志×电子墨水」（衬线+流体背景）与「瑞士国际主义」（本试验采用后者，主题更成体系）。
- 可复用的纪律：所有颜色走 `:root` token 禁止现场发明 hex；单一 accent（克莱因蓝 IKB），浅底上的高亮反白必须纯黑；
- 签名元素被我抄进了 01 版：`.rule` 细线系统（1px/18% 透明度）、`.dots` 点阵（radial-gradient 12px 网格）、
  `.mark` 高亮（box-decoration-break:clone）、等宽大写 kicker（前置 24px 短线）、极致字号对比（11vw×200 字重 vs 14px 铬件）。

### 2. dashi-ppt-skill —— 「深底壳 + 主题包运行时」
- 内部基线是"swiss 深底壳"：slide 背景 `#02040c`、焦点色薄荷绿 `#46e3c6`（激活导航点拉长为 20px 胶囊——02 版的轮播圆点就是它）。
- 12 套主题包里最出挑的 theme02「炫光紫绿」：近黑底上多彩霓虹并存，是它与 guizang（单 accent+亮纸底）最大的分野。
- 海报展示体（Anton/Impact 系）只干"宣告"的活，解释性文字交给正文体——02/06 两版的大标题都遵循这条分工。

### 3. ppt-master-plus —— 「spec_lock 单一事实源 + 页面节奏」
- 它不提供出厂皮肤，而是一套"锁规范"工程：色板固定为 `background / secondary_bg / primary / accent / secondary_accent / body_text`
  六个字段，写进 spec_lock.md 后所有页面只准从这里取色。03 版把这六字段写在文件头注释里，页脚可查。
- 另一个可迁移的思想是 **page_rhythm（anchor 锚点页 / dense 高密度页 / breathing 呼吸页）三分为页面定节奏**，
  以及明确反对"每页都是均匀卡片墙"。03 版每个区块右上角都有节奏徽章，版式在整版/分栏/密排之间切换。

### 4. Jingge-PPT-sense-deck-skill —— 「纸上的编辑部」
- Editorial Cinematic Paper：纸/墨/牛血红三色构图，宋体大标题是论点、照片是证据不是装饰。
- 签名元素全部进 04 版：刊头 masthead（平潭旅志·第叁期）、四角括号 `.ecp-corner`（纯背景渐变实现）、
  标题下的短牛血红横线、编号事实行、**2.35:1 宽银幕剧照条**（影集主视觉改成了电影宽幅）、页脚圆形系统章。
- 纪律：仅边框、无阴影、无圆角、无玻璃；动效只许 transform/opacity。

### 5. slidesage —— 「7 套风格系统选型库」
- 仓库自带 7 套 style-system：corporate-bright / futuristic-tech / hand-drawn-editorial / japanese-editorial /
  minimalist-luxury / modern-illustration / soft-clay-3d，每套是一份 token（色板、字号 pt 阶梯、列表符、封面母题）。
- 对"个人旅行日记"选了 **japanese-editorial（和纸柔光）**：叙事反思型内容 × 大留白 × 安静圆形母题最搭，
  于是 05 版几乎没有卡片、用留白分组、`・` 中点列表、呼吸的日轮圆。
- 备选是 hand-drawn-editorial（赤陶橙#D9743B × 鼠尾草绿#4C7A6E、Comic Sans/霞鹜文楷、`–` 短横列表），
  手绘速写本气质，想要可以再加一版。

### 6. frontend-slides —— 「34 个大胆模板的图鉴」
- bold-template-pack 里有 34 个模板（8-bit-orbit / biennale-yellow / broadside / capsule / cartesian / cobalt-grid /
  coral / daisy-days / editorial-forest / pin-and-paper / retro-windows / sakura-chroma / soft-editorial / vellum …）。
- 选 **coral** 做成 06 版：它明说源头是 mid-century travel posters——珊瑚/墨/奶油三个实色面硬边相接，
  45° 斜纹 hatch、12% 透明度巨型底纹编号、5px 珊瑚顶边白卡、珊瑚圆点+奶油光环的时间线节点，全部照搬。
- 次选 editorial-forest（森绿×灰玫瑰×燕麦纸、Source Serif 500 恒字重、圆形 monogram 章），想要书卷气可再加。

## 三、横向观察（为什么你的原版会显得"单一"）

1. **配色习惯**：原版是"深底 + 多彩渐变 + 圆角卡"的常见组合。上面 6 版证明：亮纸底（01/04/05/06）、
   单锚点色（01）、硬边色块无圆角（01/04/06）、衬线大标题（04/05）……每换一条规则，气质就完全不同。
2. **装饰物差异**：瑞士靠细线+点阵，Jingge 靠四角括号+系统章，slidesage 靠留白+圆，coral 靠斜纹+巨型编号——
   装饰不是"加东西"，而是给版面一个可辨识的签名。
3. **字体即风格**：等宽铬件（01/03）、海报体（02/06）、宋体（04）、衬线（05），标题换字体比换颜色更立竿见影。
4. **留白与密度**：01/03 强调信息密度与表格化，05 反其道用大留白；同一种内容可以一密一疏。

## 四、工程说明

- 六版共用 `assets/data.js`（行程数据，与主版同步）+ `assets/app.js`（交互逻辑）。
- **localStorage / IndexedDB 键名与主版《行程.html》完全一致**：你在任何一版记的账、传的照片、勾的清单、
  写的注意事项，其余五版和主版全部共享。想让某风格用独立数据，改 app.js 顶部的 KEY 常量即可。
- 路线图改成了每风格手绘的 SVG（去掉了腾讯地图 JS），一是离线可看，二是地图本身就是风格展示位。
- 字体策略：全部使用系统字体栈（Impact/Bebas fallback、宋体、楷体、雅黑），不依赖 CDN，断网也能看。
  装了相应字体（Anton、Bebas Neue、ZCOOL XiaoWei、霞鹜文楷）会自动更漂亮。
