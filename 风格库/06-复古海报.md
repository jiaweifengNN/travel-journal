# 06-复古海报

> 奶油+珊瑚×墨三实色硬边相接 + **Bebas 海报体 + 楷体** + 45° 斜纹 + 巨型幽灵数字 + 珊瑚顶边白卡 + 黑底页脚。
> 源头是 mid-century travel posters，热烈醒目，朋友圈封面级。

## 元信息

- **风格名**：复古珊瑚海报（Coral Travel Poster）
- **来源**：zarazhangrui/frontend-slides（bold-template-pack 34 模板里的 `coral`）
- **一句话气质**：热烈、醒目、旅行海报感、硬边色块
- **适合场景**：旅行海报感、热烈醒目、朋友圈封面、度假/海岛/热烈目的地
- **已用于**：平潭自驾 → `2026-十一平潭自驾/风格试验/06-复古海报.html`

## 配色（`:root`）

```css
:root{
  --cream:#F5F0E8; --cream2:#E8E0D4; --grey:#6B6B6B; --neutral:#B0B0B0;
  --coral:#E85D5D; --coral2:#D44A4A; --ink:#1A1A1A;
  --display:"Bebas Neue","Anton","Impact","Haettenschweiler","Arial Narrow",sans-serif;
  --cjk-display:"ZCOOL XiaoWei","KaiTi","STKaiti","Microsoft YaHei",sans-serif;
  --body:"Inter","Segoe UI","PingFang SC","Hiragino Sans GB","Microsoft YaHei",sans-serif;
}
```

**配色纪律**：
- 三实色：奶油 `--cream` / 珊瑚 `--coral` / 墨 `--ink`，**硬边相接**，不渐变不柔化。
- 珊瑚是绝对主角，墨是衬托与反差，奶油是底。
- 无中间灰过渡，色块直接切。

## 字体

- **拉丁标题**：`--display`（Bebas Neue / Anton 系海报体，大写窄高）
- **中文标题**：`--cjk-display`（ZCOOL XiaoWei / 楷体系，有笔锋的海报感）
- **正文**：`--body`（Inter 系）
- **字号策略**：hero 中文标题 `clamp(44px,7vw,92px)`，年份/数字用 Bebas 极大。
- **加载**：系统字体栈，装了 Bebas/ZCOOL 更地道，断网 fallback 可用。

## 全局纪律

```css
body{background:var(--cream);color:var(--ink);font-family:var(--body);line-height:1.7}
::selection{background:var(--coral);color:var(--cream)}
```

- **圆角**：禁止（硬边是海报感的核心，与 01/04 同阵营）
- **阴影**：禁止（色块硬切，不靠投影）
- **玻璃**：禁止
- **动效**：微过渡即可

## 签名元素

### 1. 32%/68% 硬切 hero（珊瑚块 + 墨块）

hero 分两块：上方 32% 珊瑚块（年份+斜纹+幽灵数字），下方 68% 墨块（标题+路线）。
```css
.hero-coral{background:var(--coral);position:relative;overflow:hidden;display:flex;flex-direction:column;justify-content:flex-end;padding:36px 30px}
.hero-ink{background:var(--ink);color:var(--cream);padding:52px clamp(28px,6vw,84px);display:flex;flex-direction:column;justify-content:center}
```

### 2. 45° 斜纹 hatch

```css
.hero-coral::before{content:"";position:absolute;inset:0;background:repeating-linear-gradient(45deg,transparent,transparent 20px,rgba(0,0,0,.07) 20px,rgba(0,0,0,.07) 40px)}
```
珊瑚块和 prep 块都叠 45° 斜纹，mid-century 海报标志性纹理。

### 3. 巨型幽灵数字 `::after`

```css
.hero-coral::after{content:"10";position:absolute;right:-18px;top:-44px;font-family:var(--display);font-size:clamp(150px,18vw,240px);color:rgba(0,0,0,.12);line-height:1}
```
珊瑚块右上角浮一个 12% 透明度的巨型「10」（十月），海报式视觉锤。prep 块同理浮一个「!」。

### 4. 珊瑚顶边白卡 + 墨左边框

```css
.prep-item{display:flex;align-items:center;gap:12px;background:var(--cream);color:var(--ink);border-left:5px solid var(--ink);padding:12px 14px;margin-bottom:9px;font-size:15px;font-weight:600}
```
清单项是白卡 + 5px 墨左边框；prep 整块是珊瑚底 + 珊瑚顶边白卡。

### 5. 黑底页脚 + 海报体大字

页脚用墨黑底 + Bebas/ZCOOL 大字，与 hero 呼应，首尾都是「重色块」。

## 反模式

- ❌ 圆角/阴影/渐变（硬边实色是海报感核心）
- ❌ 用衬线/宋体（要 Bebas 海报体 + 楷体）
- ❌ 珊瑚用太少（它是主角，hero/prep/footer 都要有）
- ❌ 没有斜纹或幽灵数字（少了这俩就丢了 mid-century 味）
- ❌ 中间灰过渡（色块直接硬切）

## 备选（同仓库其他模板）

frontend-slides bold-template-pack 还有 33 个模板，书卷气可选 **editorial-forest**（森绿×灰玫瑰×燕麦纸、Source Serif 500 恒字重、圆形 monogram 章）；其他如 broadside 报纸、retro-zine 复古杂志、vellum 羊皮纸、sakura-chroma 樱花等都可按需新增配方。
