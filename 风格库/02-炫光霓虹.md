# 02-炫光霓虹

> 近黑底 + **多彩霓虹并存**（绿/紫/薄荷/粉/琥珀）+ Anton 海报体大标题 + 径向光晕 + 发光路线。
> 与单锚点的瑞士相反，这是「多彩共存」的发布会现场感。

## 元信息

- **风格名**：炫光霓虹（Neon Glow）
- **来源**：chuspeeism/dashi-ppt-skill（深底壳 + 12 主题包里的 theme02「炫光紫绿」）
- **一句话气质**：炫酷、年轻、有现场感、海报宣告
- **适合场景**：演唱会/音乐节/夜游/城市夜生活/年轻炫酷的旅行
- **已用于**：平潭自驾 → `2026-十一平潭自驾/风格试验/02-炫光霓虹.html`

## 配色（`:root`）

```css
:root{
  --bg:#07090b; --bg2:#0b0e12;
  --txt:#ffffff; --txt2:rgba(255,255,255,.66); --line:rgba(255,255,255,.14);
  --green:#2fe07f; --purple:#9b7dff; --blue:#4ea2ff; --lime:#b9f24a;
  --pink:#ff6fae; --amber:#ffc24a; --mint:#46e3c6;
  --display:"Anton","Impact","Haettenschweiler","Arial Narrow Bold","Microsoft YaHei",sans-serif;
  --sans:"Archivo","Inter","Segoe UI","PingFang SC","Hiragino Sans GB","Noto Sans SC","Microsoft YaHei",sans-serif;
  --mono:"Space Mono","JetBrains Mono",Consolas,"Courier New",monospace;
}
```

**配色纪律**：
- 多彩并存是它的标志（与 01 单锚点正相反）：绿/紫/蓝/粉/琥珀/薄荷可同时出现。
- 但每个元素**只吃一个色**，靠分工而非混色：导航 logo 用渐变文字、eyebrow 用薄荷、deadline 用粉、勾选用绿薄荷渐变。
- 焦点色 = `--mint:#46e3c6`（dashi 基线的激活色）。

## 字体

- **标题体**：`--display`（Anton / Impact 系海报体，只干「宣告」的活，大写）
- **正文体**：`--sans`（Archivo / Inter 系）
- **铬件**：`--mono`（Space Mono 系，标签/导航/数据）
- **字号策略**：hero 标题 `clamp(40px,8vw,96px)` 大写海报体，line-height .96 紧凑。
- **加载**：系统字体栈，Anton/Impact 有则用、无则 fallback。断网可用。

## 全局纪律

```css
body{background:var(--bg);color:var(--txt);font-family:var(--sans);line-height:1.65;overflow-x:hidden}
::selection{background:var(--mint);color:#04110d}
```
背景叠 4 个径向光晕（紫/绿/粉/蓝各一角）：
```css
background:
  radial-gradient(38% 30% at 12% 8%,rgba(155,125,255,.16),transparent 70%),
  radial-gradient(34% 28% at 88% 14%,rgba(47,224,127,.10),transparent 70%),
  radial-gradient(40% 32% at 78% 78%,rgba(255,111,174,.09),transparent 70%),
  radial-gradient(36% 30% at 18% 82%,rgba(78,162,255,.10),transparent 70%);
```

- **圆角**：允许（胶囊 999px / 12-14px 卡片）
- **阴影**：允许发光（`text-shadow` 霓虹光晕、`box-shadow` 聚焦环）
- **玻璃**：允许（导航 `backdrop-filter:blur(12px)`）
- **动效**：允许过渡、发光呼吸

## 签名元素

### 1. 霓虹发光标题 `.neon-*`

```css
.display{font-family:var(--display);text-transform:uppercase;letter-spacing:.02em;line-height:.96;font-weight:400}
.neon-green{color:var(--green);text-shadow:0 0 22px rgba(47,224,127,.45)}
.neon-purple{color:var(--purple);text-shadow:0 0 22px rgba(155,125,255,.5)}
.neon-pink{color:var(--pink);text-shadow:0 0 22px rgba(255,111,174,.4)}
```
大标题按词分色发光，是它最抓眼的签名。

### 2. 渐变文字 logo

```css
nav .logo{font-family:var(--display);font-size:16px;text-transform:uppercase;background:linear-gradient(90deg,var(--green),var(--blue),var(--purple));-webkit-background-clip:text;background-clip:text;color:transparent}
```

### 3. 发光 eyebrow（前置发光短线）

```css
.hero .eyebrow{font-family:var(--mono);font-size:12px;letter-spacing:.3em;text-transform:uppercase;color:var(--mint);display:inline-flex;align-items:center;gap:10px}
.hero .eyebrow::before{content:"";width:34px;height:2px;background:var(--mint);box-shadow:0 0 12px var(--mint)}
```

### 4. 胶囊导航 + 激活拉长点

```css
nav a{font-family:var(--mono);font-size:11.5px;letter-spacing:.12em;text-transform:uppercase;padding:5px 12px;border:1px solid transparent;border-radius:999px}
nav a.hot{color:var(--mint);border-color:rgba(70,227,198,.5)}
```
（dashi 基线的轮播圆点激活时拉长为 20px 胶囊，同源语言。）

### 5. 发光 SVG 路线

路线图用 SVG `feGaussianBlur` 滤镜做霓虹描边发光，节点是发光圆点。


## 反模式

- ❌ 亮底（霓虹必须在近黑底上才发光）
- ❌ 单色到底（多彩并存是它的灵魂，但每元素一色）
- ❌ 用衬线/宋体（破坏海报体宣告感）
- ❌ 发光过度到看不清字（text-shadow 控制在 22px/0.4-0.5 透明度）
- ❌ 直角硬边（它是胶囊 + 圆角的，与 01/04 相反）
