## 怎么用（给你）

1. **选风格**：打开 [风格索引.md](./风格索引.md)，按场景挑。已实现的 6 种可直接报编号；其余报"仓库:风格名"（如「slidesage 的 minimalist-luxury」「frontend-slides 的 vellum」）。
2. **下指令**：例如「用 04 电影纸感做 2027 春天京都攻略」或「用 frontend-slides 的 vellum 做一份冰岛攻略」。
3. **我读配方 → 开工**：已实现的直接套骨架；未实现的按归档 spec（palette+字体+装饰）+ 既有旅行页骨架制作。

## 配方 vs 归档的区别

- **已实现配方**（`已实现配方/`）：做过完整旅行 HTML 页，含 `:root` 变量、签名元素 CSS、页面骨架、组件配方、反模式。复刻最快、最准。
- **仓库归档**（`仓库归档-A*`）：登记了该仓库**所有**风格的真实 spec（palette/字体/场景/装饰），但还没落成旅行页。首次用需我按 spec 现做，稍慢。

## 怎么新增风格

当你丢给我新风格 skill 仓库或参考样例：
1. 研究，提炼辨识度最高的风格（一个仓库可能含多套，全登记）。
2. 若做成旅行页 → 复制 [`已实现配方/_新增风格模板.md`](./已实现配方/_新增风格模板.md) 填满，放 `已实现配方/`。
3. 若仅登记 spec → 在对应仓库归档追加（或新建归档），给 palette/字体/场景/装饰。
4. 回填 [风格索引.md](./风格索引.md)。
5. 配方/归档必须给**真实 CSS 变量或 hex**和**可复制片段**，不能只写形容词。
