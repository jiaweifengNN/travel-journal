# 05-和纸柔光

> 和纸米底 + 闷红×松绿双辅色 + **Georgia 衬线** + 大留白 + **呼吸日轮圆** + 中点列表 + 无卡片。
> 最安静的一版：用留白分组而非卡片，照片不抢戏，叙事反思型。

## 元信息

- **风格名**：和纸柔光（Japanese Editorial / Washi）
- **来源**：vedraut/slidesage（7 套 style-system 里的 `japanese-editorial`）
- **一句话气质**：安静、治愈、手账日记、留白即设计
- **适合场景**：手账日记感、安静治愈的旅行、人文反思、不想照片抢戏的行程
- **已用于**：平潭自驾 → `2026-十一平潭自驾/风格试验/05-和纸柔光.html`

## 配色（`:root`）

```css
:root{
  --bg:#F6F3EC; --bg-alt:#ECE6DA;
  --ink:#2B2A28; --ink-soft:#7A756B;
  --accent:#B5524B; --accent2:#3F6F66;
  --sand:#C99A57;
  --serif:Georgia,"Times New Roman","Songti SC","Source Han Serif SC","Noto Serif CJK SC","SimSun",serif;
  --sans:"Helvetica Neue",Arial,"PingFang SC","Hiragino Sans GB","Microsoft YaHei",sans-serif;
}
```

**配色纪律**：
- 双辅色：闷红 `--accent`（强调/勾选/路线）× 松绿 `--accent2`（完成态/副标）。
- 底色和纸米，墨色偏暖灰 `#2B2A28` 而非纯黑，柔。
- 无高饱和、无渐变（呼吸圆除外，那是径向渐变）。

## 字体

- **标题/正文**：`--serif`（Georgia 系 + 中文宋体 fallback，衬线是治愈感核心）
- **铬件/标签/路线**：`--sans`（Helvetica 系窄无衬线，与衬线对比）
- **字号策略**：line-height 1.95 极松，字号克制（hero 标题 clamp 中等），靠留白而非大字。
- **加载**：系统字体栈，断网可用。

## 全局纪律

```css
body{background:var(--bg);color:var(--ink);font-family:var(--serif);line-height:1.95;font-size:16px}
::selection{background:var(--accent);color:#fff}
```

- **圆角**：允许（圆勾选 50%、胶囊按钮 999px，但克制）
- **阴影**：仅呼吸圆有柔光晕，其余无
- **玻璃**：仅导航 `backdrop-filter:blur(8px)`
- **动效**：呼吸圆 7s 缓动 + 微过渡

## 签名元素

### 1. 呼吸日轮圆 `.circle-mark`（hero 母题）

```css
.hero .circle-mark{width:150px;height:150px;border-radius:50%;margin:0 auto 36px;
  background:radial-gradient(circle at 38% 34%,rgba(181,82,75,.92),rgba(181,82,75,.75) 58%,rgba(63,111,102,.35) 59%,rgba(63,111,102,.28) 100%);
  box-shadow:0 14px 44px rgba(181,82,75,.16);
  animation:breathe 7s ease-in-out infinite;}
@keyframes breathe{0%,100%{transform:scale(1);opacity:.92}50%{transform:scale(1.06);opacity:1}}
```
红日裹一层松绿光晕，7 秒呼吸缩放。是最强签名，也是全页唯一的「动」。

### 2. 无卡片 · 留白分组

不用卡片/边框，章节之间靠**大留白**分隔。这是它与其他 5 版最大的分野。

### 3. 中点列表 `・`

列表项用 `・` 中点（日式），不用 `•` 或 `-`。

### 4. 圆形勾选

```css
.prep-item .box{flex:none;width:17px;height:17px;border-radius:50%;border:1.5px solid var(--accent);cursor:pointer;transform:translateY(2.5px)}
.prep-item.done .box{background:var(--accent2);border-color:var(--accent2)}
```
圆勾选，完成态变松绿。

### 5. 胶囊按钮 + 收尾圆点

```css
.btn{cursor:pointer;border:none;background:var(--accent);color:#fff;border-radius:999px;font-family:var(--sans);font-size:13px;letter-spacing:.14em;padding:11px 26px}
.btn-ghost{background:transparent;color:var(--ink-soft);border:1px solid rgba(43,42,40,.2)}
```
页脚一个圆点收尾标记。

## 反模式

- ❌ 用卡片/边框分组（留白分组是灵魂）
- ❌ 高饱和色 / 多彩（和纸要柔）
- ❌ 信息太密（line-height 1.95 + 大留白，疏即美）
- ❌ 用无衬线做正文（Georgia 衬线是治愈感核心）
- ❌ 动效太多（只有呼吸圆一个动）

## 备选（同仓库其他 style-system）

slidesage 还有 6 套：corporate-bright / futuristic-tech / hand-drawn-editorial / minimalist-luxury / modern-illustration / soft-clay-3d。
其中 **hand-drawn-editorial**（赤陶橙 #D9743B × 鼠尾草绿 #4C7A6E、Comic Sans/霞鹜文楷、`–` 短横列表）是手绘速写本气质，可作为第 7 版候选。
