# 03-暗夜科技

> 深夜蓝底 + **spec_lock 六字段配色锁** + 网格背景 + 描边巨型序号 + 节奏徽章。
> 它不提供出厂皮肤，是一套「锁规范」工程：所有页面只准从 spec_lock 取色，并为每页定节奏。

## 元信息

- **风格名**：暗夜科技·节奏版（Dark Tech · page_rhythm）
- **来源**：gnuhpc/ppt-master-plus（spec_lock 单一事实源 + page_rhythm 三分法）
- **一句话气质**：工程感、信息密度高、节奏分明、规范即美学
- **适合场景**：信息密集的攻略、工程/技术型内容、注重节奏与层级、多表格多数据
- **已用于**：平潭自驾 → `2026-十一平潭自驾/风格试验/03-暗夜科技.html`

## 配色（`:root`）— spec_lock 六字段

```css
:root{
  --bg:#0b0e14; --bg2:#131826;          /* background / secondary_bg */
  --primary:#4cc9f0; --accent:#f72585;  /* primary / accent */
  --accent2:#ffd166;                    /* secondary_accent */
  --txt:#e6edf3; --txt2:#8b95a8;        /* body_text / helper */
  --line:rgba(76,201,240,.22); --line2:rgba(230,237,243,.08);
  --sans:"Segoe UI","PingFang SC","Hiragino Sans GB","Microsoft YaHei",system-ui,sans-serif;
  --mono:Consolas,"Courier New",monospace;
}
```

**配色纪律（spec_lock 的核心）**：
- 六字段固定为 `background / secondary_bg / primary / accent / secondary_accent / body_text`。
- 写进 spec_lock 后，全站**只准从这六字段取色**，禁止现场发明 hex。03 版把这六字段写在文件头注释里，页脚可查。
- primary=青(数据/链接/主结构)，accent=品红(警示/强调)，secondary_accent=琥珀金(数值/完成态)。

## 字体

- **标题/正文**：`--sans`（Segoe UI / 雅黑 系，无衬线工业感）
- **铬件**：`--mono`（Consolas，所有 kicker/标签/数据/徽章/编号）
- **字号策略**：克制的中等字号，靠 mono 标签 + 描边巨号制造层级，不靠超大字。
- **加载**：纯系统字体栈，断网可用。

## 全局纪律

```css
body{background:var(--bg);color:var(--txt);font-family:var(--sans);line-height:1.65;position:relative}
::selection{background:var(--accent);color:#fff}
```
背景叠**网格**（与 01 的点阵不同，这里是线条网格）+ 双色光晕：
```css
background-image:
  linear-gradient(var(--line2) 1px,transparent 1px),
  linear-gradient(90deg,var(--line2) 1px,transparent 1px);
background-size:32px 32px;  /* 网格 */
/* + 双色光晕 */
radial-gradient(42% 34% at 14% 6%,rgba(76,201,240,.13),transparent 70%),
radial-gradient(38% 30% at 88% 90%,rgba(247,37,133,.08),transparent 70%);
```

- **圆角**：允许但小（3-8px，工程感而非柔软感）
- **阴影**：克制，靠边框 + 微光晕而非投影
- **玻璃**：允许（导航 `backdrop-filter:blur(10px)`）
- **动效**：仅过渡，克制

## 签名元素

### 1. 节奏徽章 `.rhythm`（page_rhythm 三分法）

```css
.rhythm{font-family:var(--mono);font-size:10px;letter-spacing:.22em;padding:3px 9px;border:1px solid var(--line);color:var(--primary);border-radius:3px}
.rhythm.anchor{color:var(--accent);border-color:rgba(247,37,133,.5)}
.rhythm.breathing{color:var(--accent2);border-color:rgba(255,209,102,.4)}
.rhythm.dense{color:var(--primary)}
```
每个区块右上角标节奏类型：`ANCHOR` 锚点页(品红) / `DENSE` 高密度页(青) / `BREATHING` 呼吸页(金)。这是 ppt-master-plus 最可迁移的思想——**为每页定节奏，反对均匀卡片墙**。

### 2. 描边巨型序号 `data-idx`

章节用巨型数字作为描边轮廓（stroke 文字，非填充），作为视觉锚点：
```css
/* 大号描边数字，颜色用 -webkit-text-stroke，透明填充 */
.idx{font-family:var(--mono);font-size:120px;-webkit-text-stroke:1.5px var(--line);color:transparent;line-height:1}
```

### 3. 网格背景 + 双色光晕
（见全局纪律）网格 = 工程坐标系，双色光晕 = 氛围。

### 4. 等宽 spec 小标 + mono 数据行

```css
.hero .spec{font-family:var(--mono);font-size:11px;letter-spacing:.2em;color:var(--primary)}
```
所有数据/标签走等宽，营造「技术规格表」感。

### 5. 完成态青绿渐变勾选

```css
.prep-item.done .box{background:linear-gradient(135deg,var(--primary),#2ec4b6);border-color:transparent}
```

## 反模式

- ❌ 现场发明不在 spec_lock 六字段里的 hex（破坏规范即美学）
- ❌ 所有区块用同一节奏（必须区分 anchor/dense/breathing）
- ❌ 没有节奏徽章（它是最辨识的签名）
- ❌ 圆角过大变柔软（工程感需要小圆角 3-8px）
- ❌ 用衬线字体（破坏技术规格感）
