# 01-瑞士国际主义

> 纸白底、黑色印刷字、**单一克莱因蓝锚点**、零圆角零阴影、等宽铬件、网格点阵。
> 纪律即风格：锁死 token，全站只从一个 accent 取色。

## 元信息

- **风格名**：瑞士国际主义（Swiss International）
- **来源**：alphane-ai/guizang-ppt-skill-mod（双风格里的「瑞士国际主义」主题）
- **一句话气质**：极简、数据控、打印友好、字重两极
- **适合场景**：数据型攻略、极简主义、需要打印的行程单、强调精确感
- **已用于**：平潭自驾 → `2026-十一平潭自驾/风格试验/01-瑞士国际主义.html`

## 配色（`:root`）

```css
:root{
  --paper:#fafaf8; --grey-1:#f0f0ee; --grey-2:#d4d4d2; --grey-3:#737373;
  --ink:#0a0a0a; --text-2:#525252; --text-helper:#737373;
  --accent:#002FA7; --accent-on:#ffffff; --warn:#FF6B35;
  --sans:"Inter","Helvetica Neue","Helvetica","Arial","PingFang SC","Hiragino Sans GB","Source Han Sans SC","Noto Sans SC","Microsoft YaHei",system-ui,sans-serif;
  --mono:"JetBrains Mono","IBM Plex Mono","SF Mono","Cascadia Code",Consolas,"Courier New",monospace;
}
```

**配色纪律**：
- **单一锚点色** = `--accent:#002FA7`（克莱因蓝 IKB）。全站强调色只用它，禁止发明第二个 hex。
- 浅纸底上的高亮反白必须纯黑 `--ink`，不要用灰。
- 所有颜色走 token，现场不许出现裸 hex。

## 字体

- **标题/正文**：`--sans`（Inter 系 + 中文无衬线 fallback）
- **铬件**（kicker/标签/导航/数据/路线）：`--mono`（JetBrains Mono 系）
- **字号策略**：极致对比——hero 标题 ~11vw × 字重 200/700 两极，正文 14-16px，铬件 11-13px。
- **加载**：纯系统字体栈，不依赖 CDN，断网可用。装了 Inter / JetBrains Mono 更漂亮。

## 全局纪律

```css
*{box-sizing:border-box;margin:0;padding:0;border-radius:0!important;box-shadow:none!important}
body{background:var(--paper);color:var(--ink);font-family:var(--sans);line-height:1.55;-webkit-font-smoothing:antialiased}
::selection{background:var(--accent);color:var(--accent-on)}
```

- **圆角**：禁止（`border-radius:0!important` 全局）
- **阴影**：禁止（`box-shadow:none!important` 全局）
- **玻璃/模糊**：禁止
- **动效**：仅 transform/opacity，克制

## 签名元素

### 1. 点阵 `.dots`（网格母题）

```css
.dots{background-image:radial-gradient(currentColor 1px, transparent 1px);background-size:12px 12px;opacity:.16}
```
hero 右上角放一块 220×160 的点阵装饰，是瑞士网格的可视化签名。

### 2. 细线系统 `.rule`

```css
.rule{width:100%;height:1px;background:currentColor;opacity:.18;border:none}
.rule.thick{height:2px;opacity:1}
.rule.accent{background:var(--accent);opacity:1;height:2px}
```
章节之间用 1px/18% 透明度细线分隔；章节顶用 2px 纯黑粗线。

### 3. 等宽大写 kicker（前置短线）

```css
.kicker{font-family:var(--mono);font-size:13px;letter-spacing:.24em;text-transform:uppercase;opacity:.85;display:inline-flex;align-items:center;gap:.8em}
.kicker::before{content:"";width:24px;height:1px;background:currentColor}
```
每个区块顶部一行等宽大写小标题，前面带 24px 短线。

### 4. 克莱因蓝色块 prep（反白 + 巨型 CHECK 水印）

```css
.prep{background:var(--accent);color:var(--accent-on);padding:28px 28px 20px;position:relative}
.prep::after{content:"CHECK";position:absolute;right:24px;top:20px;font-family:var(--mono);font-size:64px;font-weight:700;letter-spacing:.06em;opacity:.14;line-height:1}
```
「关键预约」整块用 IKB 反白底，右上角浮一个 14% 透明度的巨型 CHECK——全页唯一的色块，锚点感极强。

### 5. 等宽路线 + 蓝色箭头

```css
.hero .route{font-family:var(--mono);font-size:14px;letter-spacing:.08em;color:var(--text-2)}
.hero .route .arr{color:var(--accent);padding:0 2px}
```

## 反模式

- ❌ 引入第二个强调色（瑞士的精髓是单锚点）
- ❌ 用圆角或阴影（全局禁用）
- ❌ 用衬线字体（破坏工业精确感）
- ❌ 渐变背景（瑞士是实色 + 细线 + 点阵）
- ❌ 卡片化堆叠（用细线分隔 + 留白，不要卡片）
