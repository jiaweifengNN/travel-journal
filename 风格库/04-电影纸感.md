# 04-电影纸感

> 档案纸底 + 牛血红单强调 + **宋体大标题** + 四角括号 + 报头 masthead + 2.35:1 宽银幕剧照条 + 圆形系统章。
> 纸上的编辑部：照片是证据不是装饰，宋体是论点。

## 元信息

- **风格名**：编辑部电影纸感（Editorial Cinematic Paper）
- **来源**：jxshow/Jingge-PPT-sense-deck-skill
- **一句话气质**：杂志特辑、照片叙事、印刷质感、书卷气
- **适合场景**：照片为主的旅行、杂志特辑感、文艺/人文目的地、有故事性的行程
- **已用于**：平潭自驾 → `2026-十一平潭自驾/风格试验/04-电影纸感.html`

## 配色（`:root`）

```css
:root{
  --paper:#F1EEE4; --paper2:#E4DED0; --card:#F7F4EB;
  --oxblood:#7A2F2B; --weak:#D8C1BA;
  --ink:#141311; --sub:#49443C; --meta:#746D61;
  --rule:#B8B0A1; --rule2:#D3CCBF;
  --night:#171816; --on-night:#F3EEE4;
  --serif:"Songti SC","STSong","Source Han Serif SC","Noto Serif CJK SC","SimSun",serif;
  --meta-font:"Arial Narrow","Helvetica Neue","PingFang SC","Microsoft YaHei",sans-serif;
}
```

**配色纪律**：
- 三色构图：纸 `--paper` / 墨 `--ink` / 牛血红 `--oxblood`。
- 牛血红是唯一强调色，**每处 ≤2 处**用（标题红字、短下划线、deadline、章节编号），克制。
- 无渐变、无多彩。

## 字体

- **标题/正文**：`--serif`（宋体 Songti SC 系，大标题用宋体是论点感的核心）
- **铬件/报头/标签/路线**：`--meta-font`（Arial Narrow 系窄体）
- **字号策略**：宋体大标题撑场，窄体小字做刊头/编号/路线，line-height 1.75 较松。
- **加载**：系统字体栈，宋体是中文系统标配，断网可用。

## 全局纪律

```css
body{background:var(--paper);color:var(--ink);font-family:var(--serif);line-height:1.75}
::selection{background:var(--oxblood);color:var(--on-night)}
```

- **圆角**：禁止（与 01 同，纯印刷感）
- **阴影**：禁止
- **玻璃**：禁止
- **动效**：只许 transform/opacity
- 纪律口诀：仅边框、无阴影、无圆角、无玻璃。

## 签名元素

### 1. 四角括号 `.ecp-corner`（纯背景渐变实现）

```css
.ecp-corner{position:relative}
.ecp-corner::before{content:"";position:absolute;inset:0;pointer-events:none;background:
  linear-gradient(var(--ink),var(--ink)) top left/18px 2px,
  linear-gradient(var(--ink),var(--ink)) top left/2px 18px,
  linear-gradient(var(--ink),var(--ink)) top right/18px 2px,
  linear-gradient(var(--ink),var(--ink)) top right/2px 18px,
  linear-gradient(var(--ink),var(--ink)) bottom left/18px 2px,
  linear-gradient(var(--ink),var(--ink)) bottom left/2px 18px,
  linear-gradient(var(--ink),var(--ink)) bottom right/18px 2px,
  linear-gradient(var(--ink),var(--ink)) bottom right/2px 18px;
  background-repeat:no-repeat;}
```
四角各一个 L 形短括号，像取景框/档案标记，是最强签名。**纯 CSS 渐变，无需额外元素**。

### 2. 报头 masthead 导航

```css
nav{position:sticky;top:0;z-index:99;background:var(--paper);border-bottom:2px solid var(--ink);padding:10px 24px;display:flex;gap:14px;align-items:baseline}
nav .issue{font-family:var(--meta-font);font-size:11px;letter-spacing:.22em;color:var(--meta)}
nav a.hot{color:var(--oxblood);border-bottom:2px solid var(--oxblood)}
```
导航做成刊物报头：「平潭旅志·第叁期」+ 窄体刊期号。

### 3. 2.35:1 宽银幕剧照条

影集主视觉改成电影宽幅比例（2.35:1），每张剧照带四角括号，叙事感极强。

### 4. 章节编号 + 牛血红短下划线

```css
.sec-title .no{font-family:var(--meta-font);font-size:12px;letter-spacing:.3em;color:var(--oxblood)}
.sec-title h2::after{content:"";display:block;width:56px;height:3px;background:var(--oxblood);margin-top:12px}
```
章节用「第一章·CHECK」式编号，标题下一道短牛血红横线。

### 5. 圆形系统章（页脚）

页脚放一个圆形印章 SVG，刻「平潭自驾·系统章」，像档案盖章。

## 页面骨架

```
nav(masthead 报头:刊名+刊期+窄体栏目,2px 黑下边框)
  ↓
hero(overline 窄体大写 / 宋体大标题红 em / 窄体路线上下细线 / chips 整框分割 / deadline ※ 牛血红)
  ↓
sec-title(窄体红编号「第N章」/ 宋体标题 / 红短下划线 / 窄体副标) × 各章
  ↓
prep(纸卡+细边框,方框勾选)
  ↓
days(时间线:窄体日期 / 宋体叙事)
  ↓
photos(2.35:1 宽银幕剧照条 + 四角括号)
  ↓
shuizhu/expenses(表格,窄体表头)
  ↓
route(SVG,墨线+牛血红节点)
  ↓
notes(宋体正文区)
  ↓
footer(圆形系统章 + 窄体版权)
```

### 路线（上下细线框）
```css

.hero .route b{color:var(--oxblood)}

```

## 反模式

- ❌ 用无衬线做标题（宋体是论点感的核心）
- ❌ 牛血红用太多（每处 ≤2，多了变俗）
- ❌ 圆角/阴影/玻璃（破坏印刷纸感）
- ❌ 多彩（三色构图，纸/墨/红）
- ❌ 照片当装饰背景（照片是证据，要框起来正经放）
