# 仓库归档 · Jingge-PPT-sense-deck-skill

> jxshow/Jingge-PPT-sense-deck-skill — **20 套完整 deck 模板**（含 4 套带独立视觉主题）。
> 每个 deck 有 index.html + styles*.css + deck.js + content-ir.json，是完整可运行的 HTML PPT。

## 仓库特点

- 20 套 deck，按场景分：商业汇报类 + 创意叙事类。
- 有 `deck-catalog.json` 统一索引（bestFor + defaultSlides）。
- 部分带独立 theme（cyber-neon / editorial-cinematic-paper / 史诗级 / paper-craft-lab / neon-noir-city）。
- 已实现的 `04-电影纸感` 取自 editorial-cinematic-report 的 theme。

## 4 套独立视觉主题
