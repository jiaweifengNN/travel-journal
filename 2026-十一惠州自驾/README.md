# 2026 十一 · 惠州自驾

> V2 · 武汉出发，6 天，2380 公里，**3 晚睡在海边**。

## 一句话行程

9.30 下午出发 → 赣州歇脚 → 10.1 赣州宋城 + 博罗窑鸡 + 惠城老街 →
10.2 上午爬**九龙峰**，中午到双月湾扎第一晚 → 10.3 海龟湾转场盐洲岛看玄武岩 →
10.4 巽寮湾最后一顿海鲜后启程返赣 → 10.5 白天开回武汉。

**全程不回头**：赣州 → 河源 → 博罗 → 惠城 → 惠东海边，地理上是一条直线。
**全程不爬大山**：罗浮山只吃窑鸡不上飞云顶，真正的山只有免费的九龙峰。

## 三个坚持

1. **吃本地人吃的** —— 全是开了二三十年的老铺，不是投出来的网红店。
2. **睡在浪边** —— 3 晚营地都按「安静 + 有淡水 + 有厕所」筛过。
3. **慢一点** —— 去程分两天，返程也分两天，不连夜硬开。

## 最该记住的三件事

- **10.1 0:00 起高速免费**，按驶离出口时间算，9.30 那段照常缴费。
- **港口镇 / 平海镇是最后一个补给站**，进营地前把水、食材买齐。
- **10.4 下午 1 点必须启程返赣**，返程高峰拖延到傍晚要开到深夜。
