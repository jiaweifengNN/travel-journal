# 2026 十一 · 惠州自驾

> 版本：**V1**（2026-09-29 初版，后续迭代直接改这里并升版本号）
> 动态交互版见同目录 [行程.html](./行程.html)

## 基本信息

- **时间**：2026.09.30 下午 – 10.05
- **出发地 / 结束地**：武汉
- **路线**：武汉 → 赣州 → 罗浮山 → 惠城区 → 双月湾 → 盐洲岛/黑排角 → 赣州 → 武汉
- **交通**：全程自驾（**约 2150 km**）
- **住宿**：9.30 / 10.4 住赣州；10.1–10.3 **海边露营 3 晚**
- **预算参考**：约 3600 元/人（含油费、过路、住宿、营地、门票、餐饮）

赣州 → 河源 → 博罗（罗浮山）→ 惠城 → 惠东海边，**地理上是直线，全程不回头**。

## 逐日安排

### 9.30（周二）武汉 → 赣州 · 550km / 6.5h
- 13:30 武汉出发：武鄂高速 → 武汉绕城 → 沪渝高速 → 大广高速
- 20:30 抵达赣州，宿章贡区
- ⚠️ 高速免费以**驶离出口时间**为准（10.1 0:00 起），这段照常缴费，单程约 250 元

### 10.1（周三）赣州 → 罗浮山 → 惠城 · 360km + 60km
- 12:00 到博罗，**午餐：客家窑鸡**（罗浮山必吃）
- 14:00 **罗浮山**：冲虚古观 → 朱明洞；体力好爬飞云顶（1296m，2–3h），否则索道单程 70 元
- 16:30 下山前喝碗**山水豆腐花**（山泉水制作，甜咸两种）
- 18:30 晚餐：**乌记饭店**（咕噜肉、梅菜扣肉 58 元/例）
- 20:00 夜游**水东街 · 合江楼**
- 22:00 宵夜：**娟姨炖品店**（椰子炖家鸡）

### 10.2（周四）惠城 → 双月湾 · 110km · **露营第 1 晚**
- 07:00 早餐：**陈记饮食店**（凌晨 3 点现包的蒸云吞，**7:30 前到**，卖完即收）
- 08:00 **惠州西湖**：丰渚园 → 泗洲塔 → 苏堤
- 12:30 午餐：**聚鲜阁海鲜大排档**（平海镇 16 年老店，24h 营业，人均约 77）
- 14:30 抵达双月湾，**扎营**
- 17:40 **大星山观景台**看日落（⚠️ 17:00 前必须到山脚，不然上不去）
- 夜宿海边营地

### 10.3（周五）双月湾 → 海龟湾 → 盐洲岛 · **露营第 2/3 晚**
- 06:10 双月湾日出
- 09:00 **海龟湾**（门票约 30 元，会仙桥栈道是最出片的一段）
- 11:00 收营转移（**无痕露营，垃圾全带走**）
- 14:00 抵达**盐洲岛 / 黑排角**，换营地
- 15:30 **黑排角玄武岩**徒步（穿硬底防滑鞋）
- 17:00 彩石滩 / 白沙村红树林，赶海
- 18:30 海边日落

### 10.4（周六）巽寮湾 → 赣州 · 470km / 5.5h
- 09:30 **磨子石公园**（巽寮湾标志性礁石群，早到人少）
- 11:00 天后宫民俗街，买手信（矮陂梅菜干、罗浮山百草油）
- 12:00 最后一顿海鲜
- ⚠️ **13:00 正式返程是硬线**，拖到下午五点会开到深夜
- 18:30 抵达赣州

### 10.5（周日）赣州 → 武汉 · 520km / 6h
- 08:00 出发，12:00 服务区午餐，14:30 到家

## 注意事项

1. **高速免费**：10.1 0:00 起按**驶离出口时间**算，9.30 那段照常缴费。别为省钱在服务区硬熬到 0 点。
2. **营地预约**：国庆热门营地提前 3–7 天，有水有厕所的尤其紧张。
3. **大星山日落**：17:00 前到山脚，不然上不去。
4. **海边露营**：风大 → 防风绳加重压角；夜里凉 → 带厚毯；务必看**潮汐线**，别搭在涨潮区。
5. **黑排角**：崖高浪大、**无救生员，不建议下海游泳**，拍照别踩湿滑边缘。
6. **补给时点**：进营地前最后一站是港口镇/平海镇，之后超市远且贵。
7. **无痕露营**：垃圾全部带走。
8. **10.4 返程**：13:00 出发是硬线，返程高峰别指望飙车。
