## 基本信息

- **时间**：2026.09.30 下午 – 10.05
- **出发地 / 结束地**：武汉
- **路线**：武汉 → 赣州 →（龙川·霍山 可选）→ 河源 → 博罗 → 惠城区 → 惠东九龙峰 → 双月湾 → 盐洲岛/黑排角 → 赣州 → 武汉
- **交通**：全程自驾（**约 2380 km**，驾驶约 30 小时，摊在 6 天）
- **住宿**：9.30 / 10.4 住赣州；10.1–10.3 **海边露营 3 晚**
- **预算参考**：约 3600 元/人（含油费、过路、住宿、营地、门票、餐饮）

**关键路径**：武汉南下走武阳高速 + G45 大广高速 → 龙河高速 → 长深高速。
赣州 → 河源 → 博罗（罗浮山）→ 惠城 → 惠东海边，**地理上是直线，全程不回头**。

> ⚠️ **里程纠偏（V2）**：V1 把武汉–赣州写成 550km，实际是 **650km**（武阳高速 + 大广，导航 7h26m）；赣州–武汉同理是 650km 而非 520km。这个差值直接决定 9.30 晚上睡哪，别按 V1 的数安排。

## 逐日安排

### 9.30（周二）武汉 → 赣州 · **650km / 7.5h**（国庆实际 8–8.5h）
- 13:30 武汉出发：武鄂高速 → 武汉绕城 → 沪渝高速 → 武阳高速 → 大广高速
- 16:00 服务区休整 + 加满油（**江西段服务区间距偏大**）
- 18:30 江西境内吃晚饭（高速口下来找县城小馆，比服务区好）
- 22:00 抵达赣州，宿章贡区
- ⚠️ 高速免费以**驶离出口时间**为准（10.1 0:00 起），这段照常缴费
- ⚠️ **能中午出发就别拖到下午**，650km 国庆当天要 8 小时以上

### 10.1（周三）赣州 → 河源 → 博罗 → 惠城 · 360km + 60km
- 07:30 赣州早餐 + **江南宋城**（郁孤台、八境台、宋代城墙，**全部免费**，1.5h）
- 09:30 赣州出发
- **【可选】龙川·霍山**：+1.5h / 门票 40 元。丹霞地貌，广东名山，1.5 小时登顶 —— 这一路唯一值得额外爬的山
- 13:15 到博罗·罗浮山下，**午餐：客家窑鸡**（此行最值得专程吃的一顿）
- 14:30 **山水豆腐花**（甜咸两种都尝）→ **吃完就走，不进景区、不上飞云顶**
- 15:00 驱车 → 惠城区；16:00 **补给采购**（水/食材/驱蚊/防晒）
- 17:30 **惠州西湖** 或 **高榜山** 二选一（都是低强度）
- 19:00 晚餐：**乌记饭店**（咕噜肉、梅菜扣肉 58 元/例）
- 20:30 夜游**水东街 · 合江楼**；22:00 宵夜：**娟姨炖品店**
- ⚠️ **整天不爬大山**：飞云顶往返 8 公里，有驴友下来腿疼四天，后面三天全靠腿

### 10.2（周四）惠城 → **九龙峰** → 双月湾 · 70km + 60km · **露营第 1 晚**
- 07:00 早餐：**陈记饮食店**（凌晨 3 点现包的蒸云吞，**7:30 前到**，卖完即收）
- 07:45 出发 → 惠东，约 1 小时
- 08:45 **九龙峰**（此行唯一攀登的山）：惠东县城东 14km，**免费、全天开放、停车免费**。主峰尖笔峰 563 米，2739 级石阶，一路有树荫
- 11:00 登顶看九条山脊；回程看半山腰**谭公祖庙**（1434 年，儒释道共处）
- 12:15 下山 → 平海（⚠️ 登山道**全程无补给**：每人至少 2 升水 + 坚果）
- 13:00 午餐：**聚鲜阁海鲜大排档**（平海镇 16 年老店，24h 营业，人均约 77）
- 14:30 抵达双月湾，**扎营**
- 17:00 上**大星山观景台**占位（⚠️ 17:00 前必须到山脚）；17:40 日落
- 夜宿海边营地

### 10.3（周五）双月湾 → 海龟湾 → 盐洲岛 · **露营第 2/3 晚**
- 06:10 双月湾日出
- 09:00 **海龟湾**（门票约 30 元，会仙桥栈道是最出片的一段）
- 11:00 收营转移（**无痕露营，垃圾全带走**）
- 14:00 抵达**盐洲岛 / 黑排角**，换营地
- 15:30 **黑排角玄武岩**徒步（穿硬底防滑鞋）
- 17:00 彩石滩 / 白沙村红树林，赶海
- 18:30 海边日落

### 10.4（周六）巽寮湾 → 赣州 · 470km / 5.5h
- 09:30 **磨子石公园**（巽寮湾标志性礁石群，早到人少）
- 11:00 天后宫民俗街，买手信（矮陂梅菜干、罗浮山百草油）
- 12:00 最后一顿海鲜
- ⚠️ **13:00 正式返程是硬线**，拖到下午五点会开到深夜
- 18:30 抵达赣州

### 10.5（周日）赣州 → 武汉 · **650km / 7.5h**（假期返程流按 8.5h）
- 07:30 出发，12:00 服务区午餐，17:30 到家

## 注意事项

1. **高速免费**：10.1 0:00 起按**驶离出口时间**算，9.30 那段照常缴费。别为省钱在服务区硬熬到 0 点。
2. **营地预约**：国庆热门营地提前 3–7 天，有水有厕所的尤其紧张。
3. **大星山日落**：17:00 前到山脚，不然上不去。
4. **海边露营**：风大 → 防风绳加重压角；夜里凉 → 带厚毯；务必看**潮汐线**，别搭在涨潮区。
5. **黑排角**：崖高浪大、**无救生员，不建议下海游泳**，拍照别踩湿滑边缘。
6. **九龙峰装备**：登道全程无补给，每人 2 升水起；石阶有青苔，穿硬底防滑鞋；护膝和登山杖能救下山那 2739 级。
7. **补给时点**：进营地前最后一站是港口镇/平海镇，之后超市远且贵。
8. **无痕露营**：垃圾全部带走。
9. **10.4 返程**：13:00 出发是硬线，返程高峰别指望飙车。
