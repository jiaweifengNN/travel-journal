## 电车专项 · 深蓝 S05

> 按 **纯电版（CLTC 510/520km 或 620km）** 编写。若是**增程版 215Max**（纯电 215km / 综合 1310km），
> 有油箱兜底，**650km 一段一口气就到**，下面只有「胎压 / 轮胎 / 露营用电」三项适用。

### 胎压（225/60 R18，S05 全系统一规格）

- [ ] **以主驾门框标签为准**，别照搬网上电车的通用值
- [ ] S05 厂家推荐值约 **2.5 bar**（舒适值）—— 比主流电车 2.7–3.1 低一截，打高反而伤胎
- [ ] 本趟满载长途：建议 **2.7–2.8 bar**（标准值 +0.2），不超厂家上限
- [ ] **冷胎测量**：静置 3 小时以上或行驶 <2km，早上出门前测最准
- [ ] 跑完高速别放气 —— 热胎比冷胎高 0.2–0.3 属正常，放掉反而亏
- [ ] 同轴左右压差 ≤0.1 bar

### 轮胎自检（四条各十秒）

- [ ] ① **胎面沟槽**：一元硬币插进主排水沟，看得见完整一圈就该换（法定极限 1.6mm，建议 >3mm）
- [ ] ② **胎壁**：鼓包＝帘线已断，看见就换，高速必爆
- [ ] ③ **DOT 日期**：侧壁 `DOT XXXX 3523` 后四位＝2023 年第 35 周，超 6 年橡胶硬化
- [ ] ④ **气门嘴**：橡胶龟裂会慢漏，最容易漏掉的一项
- [ ] **内侧壁**：前轮打死方向才看得见，割伤常在那一面
- [ ] 这是**后置后驱** —— 后轮磨损更快，四条都要认真看

### 随车必带（这车没有备胎）

- [ ] 确认后备厢有没有备胎 —— S05 多数版本只有补胎液 + 充气泵
- [ ] 充气泵提前通一次电试试，别到路上才发现是坏的
- [ ] 补胎胶条 kit（几十块一套）
- [ ] ⚠️ **抛锚必须叫平板拖车** —— 后驱电车两轮着地拖车会反充烧电机
- [ ] 拖车前先看一眼手册「运输」章节，跟救援说清车型

### 补能节奏（650km 这一段要提前算）

- [ ] 高速实际能耗按 **17 度/百公里** 估（120km/h 以上还要更高）
- [ ] **650km 这一段需补 2 次**：纯电 520km 版高速实际约 340km，620km 版约 400km
- [ ] S05 全系 **3C 超充，30%→80% 只要 15 分钟** —— 前提要找到功率够的桩
- [ ] 每次补能按 **30–45 分钟**排进时间表（含找桩、排队、上厕所）
- [ ] 策略：**电量剩 30% 就开始找桩**，低于 15% 是在赌运气
- [ ] 优先「下高速到城区充」：桩多、队伍短、电价低（赣州 1.2–1.65 元/度，高速 1.8）

### 露营用电（6kW 外放电是这台车的强项）

- [ ] 放电枪 / 转接插排（选带过载保护的），提前在家试一遍
- [ ] 6kW 够带电磁炉（约 2.1kW）+ 灯 + 风扇，但**别同时叠满**
- [ ] 海边湿度大、有盐雾 —— 插排防沙防潮，别放地上
- [ ] 夜间 V2L 或空调，估 **一晚 15–20% 电量**
- [ ] **进营地前先在平海镇补满** —— 两个营地本身都没有桩
- [ ] 次日还要跑 100km+ 转场，出发时电量不宜低于 50%
