## 回忆.html 怎么用

打开 [回忆.html](./回忆.html)（本地双击即可，或走 GitHub Pages 在线版）：

1. **概览**：点文字直接写一句开场白，失焦自动存。
2. **📷 照片墙**：点「上传旅途照片」，多选上传，自动压缩；点图放大（灯箱，方向键翻页），每张都能写一句说明。
3. **逐日回忆**：8.28 / 8.29 两天的时间线，时间与内容都能改，随时「＋ 加一条」。
4. **🎵 演唱会专区**：场馆、时间、票价、座位、歌单（现场听一首记一首）、感受，全可编辑。
5. **🎬 演唱会相册**：现场照片单独一个相册，和旅途照片分开更好翻。
6. **碎碎念**：一句话记当下的念头。

> **数据存储**：所有文字存浏览器本地（localStorage），照片存浏览器数据库（IndexedDB，上传自动压缩到长边 1600px）。只在本机本浏览器，换设备/清缓存会丢——想永久存档的发给我写进仓库。
